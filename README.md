# Muhammed Mubariz — UAE Job Portfolio

A responsive personal portfolio designed around Muhammed Mubariz's supplied CV and public LinkedIn profile.

## Target
- Dubai, UAE
- Abu Dhabi, UAE
- Mechanical Engineer
- Maintenance / Site Engineer
- Project Planning
- Rotating Equipment
- Petrochemical / Power Plant

## Files
- `index.html` — portfolio content
- `style.css` — responsive design
- `script.js` — mobile menu + year
- `Mubariz-CV.pdf` — supplied CV

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload all files.
3. Go to Settings → Pages.
4. Select Deploy from branch → main → /root.
5. Save.

## Important
The portfolio deliberately does not claim UAE work experience. It positions the existing Saudi Arabia industrial experience for UAE opportunities.
